# OPSearch Companion

[English](README.md) · **Русский**

OPSearch Companion — небольшое приложение для Windows. Оно сообщает [OPSearch](https://opsearch.pro), с кем вы только что играли в Counter-Strike 2, чтобы сайт заполнял таблицу сравнения вашим лобби в один клик.

Это один переносимый exe-файл: без установщика и без дополнительных библиотек. Приложение не использует Steamworks, не внедряется в процессы, не читает память игры и не запускает её. Оно только читает файл кеша, который клиент Steam сам хранит на диске.

## Как начать

1. Скачайте `opsearch-companion-windows-x64.exe` со страницы [Releases](https://github.com/MascotWorld/opsearch-companion/releases) и запустите его при открытом Steam, в котором выполнен вход.
2. Приложение само определит аккаунт Steam на этом компьютере. Нажмите **Подключить через Steam**.
3. В браузере откроется opsearch.pro. Если попросит, войдите тем же аккаунтом Steam и нажмите **Подключить**. Через пару секунд приложение увидит подтверждение и начнёт отправлять лобби.

Никаких кодов копировать не нужно. Компьютер подключается только после того, как его подтвердит на сайте тот же аккаунт Steam, который определило приложение. Поэтому привязать компьютер к чужому аккаунту нельзя. Запрос, не подтверждённый за десять минут, сгорает. Каждый аккаунт Steam подключается отдельно. Отключить компьютер можно на [странице компаньона](https://opsearch.pro/companion).

## Что именно делает приложение

Здесь полный список. Если приложение делает что-то, чего здесь нет, это ошибка.

### Что оно читает на компьютере

| Что | Зачем |
| --- | --- |
| Реестр `HKCU\Software\Valve\Steam\ActiveProcess` → `ActiveUser` | Какой аккаунт Steam сейчас вошёл. |
| Реестр `HKCU\Software\Valve\Steam` → `SteamPath` | Где установлен Steam. |
| `<Steam>\config\coplay_<SteamID>.vdf` | Собственный список Steam «недавно играли вместе». |
| Переменная окружения `COMPUTERNAME` | Имя компьютера на сайте; отправляется один раз при подключении. |
| `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `OPSearch Companion` | Только чтобы показать, включён ли автозапуск. |

Раз в пять секунд приложение считает хеш файлов `coplay_*.vdf`, чтобы заметить изменения. Разбирает оно только файл того аккаунта, который сейчас вошёл в Steam **и** подключён. Файлы других аккаунтов на этом компьютере не разбираются и не отправляются. Из файла берутся только записи CS2 (приложение `730`), попадающие в двухминутное окно вокруг вашей последней игры, — это лобби, в котором вы только что были.

Больше ничего не читается: ни файлы игры, ни скриншоты, ни чат, ни данные браузера, ни другие программы.

### Что и куда отправляется

| Куда | Когда | Что |
| --- | --- | --- |
| `opsearch.pro` | Один раз, при нажатии «Подключить» | Ваш SteamID64, имя компьютера, версия приложения. |
| `opsearch.pro` | Пока ждёт подтверждения: раз в 2 секунды, не дольше 10 минут | ID запроса на подключение и его одноразовый токен. |
| `opsearch.pro` | При изменении лобби и раз в 30 секунд, пока приложение работает | Ваш SteamID64, SteamID64 игроков из последнего лобби, записанное Steam время для каждого, время проверки, версия приложения. |
| `steamcommunity.com`, `*.steamstatic.com` | Один раз на каждого игрока в окне | Запрос открытого профиля (`/profiles/<id>?xml=1`) и картинки аватара, чтобы показать ник и аватар. Данные аккаунта и токен не отправляются. |
| `api.github.com` | При запуске и раз в шесть часов | Анонимный запрос последнего релиза для проверки обновлений. |

Сам файл VDF никогда не загружается. Все запросы идут по HTTPS. Токен устройства отправляется только на opsearch.pro и не передаётся при редиректах. Сервер хранит только ваше последнее лобби; историю матчей приложение не отправляет.

### Кто видит ваше лобби

Вы сами, когда вошли на opsearch.pro тем же аккаунтом Steam. Игроки из этого лобби, вошедшие на opsearch.pro, тоже видят его, пока оно свежее (обновлялось в последние две минуты), даже без своего приложения. Больше никто.

### Что хранится на компьютере

| Что | Где |
| --- | --- |
| Токен устройства для каждого подключённого аккаунта | `%LOCALAPPDATA%\OPSearch\Companion\config.json` |
| Настройки (трей) | `%LOCALAPPDATA%\OPSearch\Companion\settings.json` |
| Запись автозапуска, только если её включить | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `OPSearch Companion` |

Токен в `config.json` позволяет этому компьютеру отправлять лобби в ваш аккаунт OPSearch. Не передавайте этот файл и не прикладывайте его к сообщениям об ошибках. Удаление файла не отключает компьютер. Отключите его на [странице компаньона](https://opsearch.pro/companion), и токен сразу перестанет работать.

### Настройки

Шестерёнка в шапке окна открывает настройки. Обе опции по умолчанию выключены.

- **Запускать вместе с Windows** добавляет приложение в автозагрузку вашего пользователя. Тогда оно стартует в фоне: в трей, если он включён, иначе свёрнутым.
- **Сворачивать в трей** добавляет значок рядом с часами. После этого «закрыть» и «свернуть» прячут окно, а не закрывают приложение. Клик по значку возвращает окно. Чтобы выйти, нажмите на значок правой кнопкой и выберите **Выйти**.

Кнопка **Пауза** внизу окна останавливает чтение и отправку, пока вы не нажмёте **Продолжить**.

## Обновления

Приложение проверяет новый релиз на GitHub при запуске и раз в шесть часов. Если он есть, внизу окна появляется **Обновить до X**. Ссылка открывает страницу релиза: скачайте новый exe и замените им старый. Подключение и настройки сохранятся.

## Ограничения

Кеш `coplay` — недокументированный файл Steam, его формат может измениться. Парсер поддерживает ту бинарную структуру KeyValues, которую Steam пишет сейчас. Steam обновляет этот файл только после того, как вы реально сыграли с кем-то, поэтому лобби появляется после начала матча, а не в главном меню. Мы ничего не утверждаем насчёт VAC и правил Steam.
